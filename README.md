# Дизайн-система

Оформление, обкатанное на «Распаковке конкурентов»: панель с сайдбаром, плотные
таблицы с залипающими колонками, светлая и тёмная темы. Голый HTML + Tailwind из
CDN — без сборки, без React, без библиотек компонентов. Переносится
копированием, а не установкой.

Репозиторий приватный и нужен для одного: чтобы в новом проекте не выдумывать
оформление заново, а взять готовое.

## С чего начать

Открыть [`starter/index.html`](starter/index.html) двойным кликом в браузере.
Там весь набор живьём: каркас, витрина компонентов и широкая таблица. Кнопка
«Тема» в сайдбаре переключает светлую и тёмную.

## Что где лежит

| Файл | Что это |
|---|---|
| [`DESIGN-SYSTEM.md`](DESIGN-SYSTEM.md) | Полная инструкция: токены, каркас, компоненты, таблицы, правила. Главный документ. |
| [`AGENTS.md`](AGENTS.md) | Короткий свод правил для ИИ-агента, который будет верстать в новом проекте. |
| [`starter/index.html`](starter/index.html) | Рабочий шаблон: каркас + витрина + демо-таблица. Из него выкидывается демо и вставляется своё. |
| [`starter/tokens.css`](starter/tokens.css) | Токены и классы, которых нет в Tailwind. Единственный источник правды по цветам. |

## Как подключить к новому проекту

**Обычный веб-проект.** Скопировать `starter/tokens.css` рядом с разметкой,
подключить `<link rel="stylesheet" href="tokens.css">`, а конфиг Tailwind и
каркас взять из `starter/index.html`.

```bash
git clone https://github.com/christophermaasi/design-system.git
```

**Google Apps Script.** Внешние файлы там не подключаются: содержимое
`tokens.css` кладётся в `<style>` внутри `Index.html`. Разделы удобно держать
отдельными HTML-файлами и вставлять через `<?!= include('Dashboard') ?>` —
именно так собран исходный проект.

**Если верстает ИИ-агент.** Репозиторий приватный, поэтому по ссылке он его не
прочитает — надо дать файлы локально: склонировать рядом с проектом, а
содержимое `AGENTS.md` положить в `CLAUDE.md` нового проекта. Дальше достаточно
писать «сделай по нашей дизайн-системе».

## Суть в восьми правилах

Подробности — в [`DESIGN-SYSTEM.md`](DESIGN-SYSTEM.md), здесь только костяк.

1. **Цвет — носитель смысла, а не украшение.** Интерфейс серый. Цветное: ряд
   графика, рост/падение, акцент блока, опорная колонка, одна акцентная
   карточка на экран.
2. **Приглушать, а не прятать.** Выключенный фильтр, прошлый период, недоступное
   — прозрачностью или `muted-foreground`.
3. **Плотность.** Это рабочий инструмент, а не лендинг: `text-sm` в интерфейсе,
   `text-[13px]` в таблицах, `text-xs` в подписях.
4. **Заголовок всегда с подзаголовком** — у раздела, у карточки, у колонки.
5. **Пустого экрана не бывает.** Три состояния у каждого раздела: загрузка,
   пусто с кнопкой выхода, ошибка.
6. **Подсказка стоит там, где возникает вопрос** — до формы, а не после неё.
7. **Переходы короткие и только по делу.** Ничего не появляется с анимацией.
8. **Мобильная раскладка одна:** сайдбар уезжает за экран, таблицы скроллятся
   вбок как есть.

## Как обновлять

Дизайн меняется в этом репозитории, а не в проектах-потребителях. Поменяли
здесь — переносим в проекты руками; автоматической связи нет и не планируется,
она бы стоила дороже, чем экономит.
